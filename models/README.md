# Models Segment

This part of the portfolio project consists of training and running models.

A thorough description of the code in this section, its purpose and how to run it is in the accompanying Jupyter notebook `Models.ipynb`.
This notebook contains instructions on setting up a virtual environment and using it in the notebook to run model code in its cells.

The file `model.py` contains an abstract base class on which all the models developed here will be built.
