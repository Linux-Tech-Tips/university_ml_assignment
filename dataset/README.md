# Dataset Analysis and Preparation

This folder contains a thorough dataset audit as well as a pipeline to preprocess the data for this project.

The dataset audit, as well as instructions on how to run it and reproduce its results, are in `dataset_audit.ipynb`.

Python code to actually load the dataset from online sources (Kaggle) is in `dataset_loader.py`.
The preprocessing and data splitting pipeline is in the file `preprocessor.py`.
